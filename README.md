# Arjun K A — Engineering Portfolio

A responsive personal engineering portfolio website designed for GitHub Pages.

## What's included
- Responsive dark-navy design
- About, experience, education, skills, projects, certificates and contact sections
- Placeholder project illustrations and document links
- Mobile navigation
- No build tools or coding framework required

## Before publishing
1. Review all personal and education details in `index.html`.
2. Replace `assets/documents/CV.pdf` with a public-safe CV PDF.
3. Replace placeholder project images in `assets/images/projects/` with your own project screenshots.
4. Add only certificates you hold to `assets/certificates/`, and update their exact names and issuers in `index.html`.
5. Replace the email and social links in the contact section.
6. Check that no confidential employer information or sensitive personal identifiers are published.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Choose **Public** if you want GitHub Pages to be available on the free plan.
3. Upload the contents of this folder to the repository root. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder—not the outer ZIP file.
4. Open the repository's **Settings → Pages**.
5. Under build and deployment, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment to finish. Your website URL should be `https://YOUR-USERNAME.github.io`.

GitHub Pages can take a few minutes to publish after the first setup. If the site does not appear immediately, check the Pages settings and deployment status.

## Important
This portfolio contains placeholders and illustrative graphics. They are not evidence of completed CAD, simulation or other projects. Replace them with real work and verified information before sharing the site with recruiters.
